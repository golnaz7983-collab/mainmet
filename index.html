🌐 Multiplayer

برای اتصال واقعی به سرور Java، Minecraft Java 26.2 را باز کن و از Multiplayer → Add Server آدرس سرور را وارد کن. یک صفحه وب معمولی نمی‌تواند خودش پروتکل Java را جای Minecraft اجرا کند.

➕ ساخت سرور رایگان

این فرم برای پنل واقعی آماده است. برای اینکه سرور واقعاً 24/7 باشد، Backend باید روی یک کامپیوتر/VPS روشن اجرا شود؛ GitHub Pages به‌تنهایی نمی‌تواند سرور Minecraft را 24/7 اجرا کند.

🇮🇷 سرورهای ایرانی

این فهرست ادعا نمی‌کند «تمام» سرورهای ایران را دارد؛ فقط سرورهای ثبت‌شده در دیتابیس سایت نمایش داده می‌شوند.

🌍 Minecraft Web

بخش Web Hub اضافه شده است. اجرای خود Minecraft Java داخل مرورگر به یک کلاینت وب/WASM جداگانه نیاز دارد؛ HTML معمولی به‌تنهایی کلاینت رسمی Java را اجرا نمی‌کند.

🎮 Web Play
