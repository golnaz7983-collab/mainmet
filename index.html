🔗 سرورهای سازگار

برای بازی مستقیم در مرورگر، سرور باید WebSocket/WSS یا پروکسی Eagler داشته باشد. IP معمولی Java به‌تنهایی کافی نیست.

📖 راهنمای ورود به سرور

1️⃣ انتخاب

از سرورهای ایرانی یک سرور را انتخاب کن و «ورود به بازی» را بزن.

2️⃣ کپی IP

IP در کلیپ‌بورد کپی می‌شود.

3️⃣ Minecraft

Minecraft Java را باز کن → Multiplayer → Add Server → IP را وارد کن.

4️⃣ Join

بعد از دیده‌شدن وضعیت سرور، روی Join Server بزن و بازی کن.
