# ArMaCraft v26.2

این بسته نسخه ارتقایافته پنل است: Multiplayer، ساخت سرور 26.2، فهرست سرورهای ایرانی، Minecraft Web، Profile/Skin/Settings و حالت Landscape موبایل.

**مهم:** GitHub Pages فقط سایت را میزبانی می‌کند و نمی‌تواند Minecraft Server را 24/7 اجرا کند. برای سرور واقعی باید `server.js` روی VPS/کامپیوتر همیشه‌روشن اجرا شود. رایگان بودن برای کاربر به معنی رایگان بودن منابع هاست نیست.

Minecraft Java 26.2 در 16 ژوئن 2026 منتشر شده و سرور رسمی Java از سایت Minecraft ارائه می‌شود. برای 26.2 به Java 25+ نیاز است.

## اجرا
1. Node.js و Java 25+ نصب.
2. `npm install`
3. `npm start`
4. سایت: `http://localhost:3000`
5. برای اتصال اینترنتی، دامنه/IP عمومی و پورت‌های میزبان باید تنظیم شوند.
6. در `server.js` مقدار `YOUR_DOMAIN` را با دامنه واقعی عوض کنید.

Web Play واقعی Minecraft Java داخل مرورگر در این نسخه پیاده‌سازی نشده؛ این بخش به یک کلاینت وب/WASM جدا نیاز دارد.
