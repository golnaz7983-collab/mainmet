# mainmet — Minecraft Java 26.2 Hub

نسخه ارتقایافته رابط سایت با نام **mainmet**.

## امکانات فعال رابط
- منوی Minecraft-style با بلاک‌های پیکسلی و دکمه‌های فعال
- بخش «بازی کردن»
- فهرست سرورهای ایرانی با بررسی آنلاین/آفلاین و تعداد بازیکنان
- دکمه ورود به بازی، کپی IP و راهنمای Join
- افزودن سرور دلخواه و ذخیره در مرورگر
- Multiplayer و نمایش سرورهای ساخته‌شده
- فرم ساخت سرور Minecraft Java 26.2
- پروفایل و نام نمایشی
- تنظیمات Graphics، زبان، صدا و تمام‌صفحه
- طراحی دسکتاپ و موبایل افقی

## نکته مهم درباره بازی واقعی
یک سایت HTML/GitHub Pages نمی‌تواند خودش پروتکل Minecraft Java را اجرا کند یا جای Minecraft Launcher/Client را بگیرد. دکمه «ورود به بازی» IP را آماده و کپی می‌کند و راهنمای اتصال را نشان می‌دهد. برای بازی واقعی باید Minecraft Java نصب و اجرا باشد.

وضعیت سرورها در رابط با MCSrvStat بررسی می‌شود و ممکن است طبق کش سرویس چند دقیقه تأخیر داشته باشد.

## Backend ساخت سرور
برای ساخت واقعی سرور:
1. Node.js نصب کن.
2. Java 25+ نصب کن.
3. `npm install`
4. `npm start`
5. سایت روی `http://localhost:3000` اجرا می‌شود.

GitHub Pages فقط frontend را میزبانی می‌کند؛ `server.js` باید روی VPS یا کامپیوتر همیشه‌روشن اجرا شود تا ساخت و اجرای سرور واقعی ممکن باشد.
