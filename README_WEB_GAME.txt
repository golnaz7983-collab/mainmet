mainmet Web Game v1

این نسخه بازی سه‌بعدی بلوکی mainmet را مستقیماً داخل سایت اجرا می‌کند.

کنترل:
W A S D = حرکت
Mouse = نگاه کردن
Space = پرش
Click چپ = شکستن بلوک
Click راست = گذاشتن بلوک
1 تا 6 = انتخاب بلوک
Esc = آزاد کردن موس
موبایل = جوی‌استیک و دکمه‌های روی صفحه

نکته:
این یک Web Game مستقل و الهام‌گرفته از سبک Minecraft است، نه کلاینت رسمی Minecraft Java 26.2.
برای Three.js به اینترنت مرورگر نیاز دارد.
